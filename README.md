# ELEMELONS

---

## About
Elemelons is a minecraft mod that adds lots of powered watermelons.
There are 4 main ones and other 2 that I made just for a test

## Why would anyone do this?
This mod was made because of food problems on my friend's server
(That's why saturated melon, which is an op food watermelon was a thing).
I thought that we were probably not the only ones to experiment this problem
and so I published it on CurseForge and this GitHub repo. That way, anyone who
wants to use it can just download it or wander around the source
